# CardPrinterSDK 对接开发文档

本文面向在 Android 原生工程中对接彩色照片打印机的客户。示例工程是 `CardPrinterSDK`，打印库版本 `libCardPrinter 1.2.100.6`。通讯和蓝牙配网使用 `fat-generic-super-fat-sdk 0.1.18`。

## 1. 对接范围

当前 Demo 只保留两条打印通道：

| 通道 | 用途 | 是否用于打印 |
| --- | --- | --- |
| 局域网 | 手机和打印机在同一网段，TCP 端口 `9100` | 是，默认通道 |
| USB | 数据线直连 | 是 |
| BLE | 只用于配网，不直接打印 | 否 |

进入页面后，通讯方式默认是「局域网」。

蓝牙配网有两种用法。STA 是打印机加入客户路由器，手机和打印机处在同一局域网。AP 是打印机自己开热点，手机直接连这台打印机的 Wi-Fi。配好之后都用局域网通道连接，配网页面不承担打开打印机、进纸和打印。

## 2. 集成文件

把下面文件放进应用模块的 `libs` 目录：

```text
app/libs/libCardPrinter_v1.2.100.6.jar
app/libs/fat-generic-super-fat-sdk-0.1.18-GA.jar
app/libs/arm64-v8a/libcardprinter.so
app/libs/arm64-v8a/libdsjlog.so
app/libs/armeabi-v7a/libcardprinter.so
app/libs/armeabi-v7a/libdsjlog.so
```

`build.gradle.kts` 需要同时打包 jar 和 so：

```kotlin
android {
    compileSdk = 36
    defaultConfig {
        minSdk = 22
        targetSdk = 36
        ndk.abiFilters.addAll(listOf("armeabi-v7a", "arm64-v8a"))
    }
    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_1_8
        targetCompatibility = JavaVersion.VERSION_1_8
    }
    sourceSets {
        getByName("main") {
            jniLibs.srcDirs("libs")
        }
    }
}

dependencies {
    implementation(fileTree(mapOf("dir" to "libs", "include" to listOf("*.jar", "*.aar"))))
}
```

只支持 `armeabi-v7a` 和 `arm64-v8a`。模拟器如果是 x86，本地库加载会失败，请用真机。

## 3. 推荐流程

```text
打印机还没入网
    -> BLE 配网
    -> STA：打印机加入路由器；AP：手机直连打印机 Wi-Fi
    -> 拿到 IP
打印机已经在局域网或打印机热点里，或使用 USB
    -> 枚举打印机
    -> 连接
    -> 需要时读取状态、耗材、版本
    -> 组正面画布并打印
    -> 打印成功后出纸
    -> 断开
```

所有 `CardPrinterAPI` 调用都放在后台线程。局域网搜索会阻塞大约 10 秒，不要和打开打印机、进纸、打印挤在同一个单线程队列里，否则搜索期间这些操作都排不进去。

接口返回 `String`。返回 `null` 表示成功，非空字符串是失败原因。调用也可能抛出 `OperationException`，两种都要处理。

## 4. 局域网枚举和连接

Demo 不使用 `CardPrinterAPI.findNetWorkPrinter()` 一次性拿列表。局域网搜索和通用网络库一致，调用 `Network.startPrinterDiscovery()`：

- 搜索开始后大约广播 10 秒。
- 每发现一台，立刻加入列表并显示。
- 显示名是「设备名 @ IP」。
- 地址框写成 `IP:9100`，例如 `192.168.1.20:9100`。
- 重复 IP 不重复加入。
- IP 为空或为 `unknown` 的结果丢弃。
- Demo 用 12 秒作为等待上限。搜索回调结束后会马上返回，不是固定空等 12 秒。

可参考 `EnumPrinterTask`、`NamedNetworkPrinter` 和 `FragmentBase`。最小写法：

```java
Network network = Network.getInstance();
network.stopPrinterDiscovery();
network.setOnPrinterFoundListener(info -> {
    if (info == null) {
        return;
    }
    String ip = info.getId();
    if (ip == null || ip.isEmpty() || "unknown".equals(ip)) {
        return;
    }
    String displayName = info.toString(); // 设备名 @ IP
    Printer printer = new Printer.NetworkPrinter(ip, "9100");
    // 回到主线程，把 displayName 加到列表，地址填 ip + ":9100"
});
network.setOnScanningChangeListener(scanning -> {
    if (!scanning) {
        // 搜索结束，解除按钮禁用
    }
});
network.startPrinterDiscovery();
```

已知 IP 时可以不搜索，直接连接：

```java
Printer printer = new Printer.NetworkPrinter("192.168.1.20", "9100");
api.connect(printer);
api.setTimeout(45000);
```

手机和打印机必须在同一局域网，防火墙需放行 UDP 发现和 TCP `9100`。

用户连续点击「枚举打印机」时，Demo 会递增请求号，只接收最后一次搜索的结果。旧任务结束得晚，也不会把列表刷回去。客户自己的页面如果每次点击都新开任务，也要做同样的丢弃，或者在开始新搜索前取消旧搜索。

## 5. USB 连接

```java
List<Printer> printers = api.findUsbPrinter();
if (printers == null || printers.isEmpty()) {
    return;
}
Printer printer = printers.get(0);
api.requestUsbPermission(printer);
api.connect(printer);
api.setTimeout(45000);
```

`findUsbPrinter()` 返回当前已经插入的设备，没有局域网那种持续广播。USB 结果在搜索结束后一次刷新。

断开：

```java
api.disconnect();
```

连接状态用 `api.isConnected()` 判断。未连接时不要打印，Demo 会提示「请先连接打印机」。

## 6. BLE 配网

配网入口在通讯方式上面，按钮文案是「BLE配网」。实现类：

- `BleScanActivity`：扫描打印机蓝牙。
- `WifiProvisionActivity`：沿用通用 Demo 的 Wi-Fi 配网命令，不走 `libCardPrinter`。

工作模式在「设置WIFI模式」里切换。设置后 Wi-Fi 模块会自动重启，蓝牙可能断开，需要重新进入配网页再查询。

| 模式 | 含义 | 之后怎么打印 |
| --- | --- | --- |
| STA | 打印机连接客户路由器 | 手机也连这个路由器，用查询到的 `IP:9100` |
| AP | 打印机自己开热点，手机直连 | 手机改连打印机热点，用热点地址，常见默认 `192.168.1.1:9100` |

页面上还有共享模式，当前打印对接不用。

STA，打印机加入路由器：

1. 打开手机蓝牙，授予蓝牙和定位权限。
2. 在扫描页选择打印机，进入配网页。页面会在后台线程连接 BLE。
3. 工作模式设为 STA。
4. 填写路由器的 Wi-Fi 名称和密码，点击「设置wifi名称密码」。名称会尽量填入手机当前连接的 Wi-Fi。
5. 可查询 Wi-Fi 名称、密码、连接状态、工作模式和 IP。
6. 查询到 IP 后，点击「使用此 IP 打印」。主界面地址会填成 `IP:9100`。
7. 确认手机和打印机在同一个路由器下，回到主界面，通讯方式保持「局域网」，再枚举或直接连接。

AP，手机直连打印机 Wi-Fi：

1. 同样先用 BLE 连上打印机。
2. 工作模式设为 AP。需要改热点时，用「设置AP参数」填写 SSID、密码和 IP；不改就沿用打印机当前值。IP 输入框默认提示 `192.168.1.1`。
3. 可查询 AP 的 SSID、密码和当前 IP。
4. 把手机 Wi-Fi 改连到打印机热点。
5. 点击「使用此 IP 打印」，回到主界面用局域网连接。手机已经连在热点上时可以枚举，地址已知时也可以直接连接，不用等枚举结束。

配网连接沿用 Demo 里的 `BleConnectGuard`。通讯库里的 BLE 连接有 10 秒超时，超时回调在连接对象尚未建立时仍会调用断开，离开页面或连接失败时可能空指针。Demo 已在应用层取消这个超时，不要为这个问题修改或重新打包 `fat-generic-super-fat-sdk`。

## 7. 打印

画布单位是毫米。标准画布宽 `CardCanvas.CARD_WIDTH = 148`，高 `CardCanvas.CARD_HEIGHT = 100`。色带面板有 `YMC`、`K`、`S`、`I`、`S2`、`W2`。

```java
CardCanvas canvas = new CardCanvas();
canvas.setDrawDirection(CardCanvas.Orientation.HORIZONTAL);

Bitmap bitmap = BitmapFactory.decodeFile(imagePath);
BitmapData image = new BitmapData(0, 0, CardCanvas.CARD_WIDTH, CardCanvas.CARD_HEIGHT, bitmap);
image.setDitherMode(BitmapData.DitherMode.NONE);
canvas.setRibbonPanel(RibbonPanel.YMC);
String addError = canvas.addData(image);
if (addError != null) {
    // addData 返回 null 表示加入成功
}

TextData text = new TextData(5, 5, 12, "姓名");
canvas.addData(text);

PrintData printData = new PrintData();
printData.setFrontCardCanvas(canvas);
printData.setUseCMS(true);
printData.setHalfOffset(0);
printData.setOffset(0, 0, 0, 0); // 左、上、右、下，单位像素
// 双面时再设置背面：printData.setBackCardCanvas(backCanvas);

if (api.getPrinterSerial() == Printer.Serial.D300Kp) {
    printData.setYMCPrintDpi(PrintData.PrintDpi.DPI300_300);
    printData.setKPrintDpi(PrintData.PrintDpi.DPI300_600);
}

String err = api.printerOp(printData);
canvas.clear();
if (err == null) {
    api.cardOp(new EjectCard());
}
```

说明：

- `BitmapData`、`TextData` 的坐标和尺寸单位是毫米，不是像素。
- 彩色图使用 `DitherMode.NONE`，并把色带面板设为彩色面板。K 色抖动时 Demo 会把面板改为 `RibbonPanel.K`。
- `setUseCMS(true)` 打开颜色管理。Demo 默认打开。
- `setHalfOffset()` 是半格色带偏移。
- `setOffset()` 是这一次打印的图像边距。
- YMC、K、S、W 分辨率只对 `D300Kp` 有效，其他系列设置会被忽略。可选 `DPI300_300`、`DPI300_600`，K 色还支持 `DPI300_1200`。
- `setPrnPath()` 和 `setPrnFileCount()` 只在需要把下发数据保存成 prn 时使用。
- 打印成功后再出纸。失败不要继续出纸。
- 出纸可使用无参 `new EjectCard()`。需要强制退纸时：

```java
EjectCard ejectCard = new EjectCard(0, 0, 0, 0);
ejectCard.setEjectType(1); // 0 正常排纸，1 强制退纸
api.cardOp(ejectCard);
```

`DC8600` 的出纸参数含义：

| 参数 | 取值 |
| --- | --- |
| ejectAction | 0 按 EDS 决定是否夹纸；1 翻转排纸；2 排纸后重启；3 排纸重试；4 夹纸 |
| cardSide | 0 按 EDS；1 正面朝上；2 反面朝上 |
| exit | 0 按面板默认出纸口 |
| ejectType | 0 正常排纸；1 强制退纸 |

其他常用纸路操作：

```java
api.cardOp(new InjectCard(3, 0, 0)); // 装纸方式、是否翻转、目标位置
api.cardOp(new MoveCard(MoveCard.PRINT_POSITION));
api.cardOp(new FlipCard());
api.cardOp(new RecycleCard(position));
api.printerOp(new InitializePrinter());
api.printerOp(new ClearPrinterCache());
api.printerOp(new PrintTestCard());
api.printerOp(new PrintSelfTestCard());
```

`InjectCard(injectModel, cardSide, position)` 中，`cardSide` 不支持 `D300Kp`：`0` 不翻转，`1` 翻转。`position`：`0` 打印位，`1` 转印完成位，`2` 非接读写位，`3` 接触读写位，`4` 磁条读写位。装纸方式按系列不同，Demo 的进纸对话框和 `InjectCard` 注释列出了 `DC8600`、`R600`、`D300Kp` 的取值。

移纸位置常量：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `PRINT_POSITION` | 0 | 打印位 |
| `TRANSFER_POSITION` | 1 | 转印位 |
| `CONTACTLESS_POSITION` | 2 | 非接读写位 |
| `CONTACT_POSITION` | 3 | 接触读写位 |
| `MAGNETIC_READY_POSITION` | 4 | 磁条准备位 |
| `MAGNETIC_SWIPE_POSITION` | 5 | 磁条刷卡位 |
| `FLIPPER_POSITION` | 6 | 翻转位 |

机型系列通过 `api.setPrinterSerial()` 指定，可选 `Printer.Serial.D300Kp`、`R600`、`DC8600`。当前 Demo 界面没有机型切换；如果进纸、出纸或分辨率要按系列区分，连接前显式设置。

## 8. 读取状态和设置

读取时先 `new` 对应对象，再交给 `getDataOp()`。对象会被填上结果。写入使用 `setDataOp()`。

```java
PrinterStatus status = new PrinterStatus();
String err = api.getDataOp(status);
if (err == null) {
    String main = status.getMainStatusInfo();
    String warning = status.getWarningStatusInfo();
    String error = status.getErrorStatusInfo();
    Integer mainCode = status.getMainStatus();
    Float headTemp = status.getPrintHeadTemperature();
    Integer battery = status.getPrintBattVolt(); // 72 表示 7.2V
    boolean charging = status.getCharging();
}
```

Demo 打开实时状态后每 500 毫秒读一次，显示机箱温度、打印头温度、加热辊温度、主状态、警告、错误、打印状态、纸片状态、电池电压和充放电。业务侧不要比这个更频繁。

`getMainStatusInfo()`、`getWarningStatusInfo()`、`getErrorStatusInfo()` 已经是中文描述，界面直接显示即可。需要自己分支判断时，把 `getMainStatus()` 等整数格式化成 8 位十六进制再查第 9 节的表：

```java
String hex = String.format("%08x", status.getMainStatus());
```

其他读取对象：

| 对象 | 作用 |
| --- | --- |
| `PrinterInfo` | 机型、厂商、序列号、生产日期、打印总数、发行数 |
| `VersionInfo` | 主程序、BOOT、FPGA、LCD 版本 |
| `ConsumablesInfo` | 色带类型和余量百分比、转印膜类型和余量、色带厚薄 |
| `PrintHeadInfo` | 打印头序列号、打印次数 |
| `CardPosition` | 当前纸片位置，`getDescribe()` 为文字 |
| `CardBoxStatus` | 发纸盒有纸或空、废纸盒满或未满 |
| `AddonInfo` | 已连接选件 |
| `PrinterSetting` | 语言、蜂鸣器、LCD、自动关机、打印模式、初始化是否忽略色带、初始化是否不排纸 |
| `InterfaceSetting` | 静态 IP、网关、超时、打印机 ID、USB ID |
| `ImageSetting` | 图像相关设置 |
| `CardSetting` | 夹纸、温控、纸片类型、出纸口、发纸方式 |
| `ConsumablesSetting` | 色带和膜带余量告警百分比，直印机加密重打次数和偏移 |

写入前先读取同一对象，只修改要改的字段，再 `setDataOp()`。自动关机时间 `0` 表示不关机，其他取值 `2` 到 `1440` 分钟。LCD 语言：`0` 中文，`1` 日文预留，`2` 英文。

固件升级把文件读成字节数组。前 5 个字节必须是 `D-380`：

```java
api.printerOp(new UpdateFirmware(firmwareBytes));
```

升级期间主状态可能是 `4d000c01` 或 `4d000c02`，不要在这时断开或重复下发。

日志：

```java
api.setLogConfig(new LogConfig(logDirectory, expireDays, level));
```

`level` 有效范围是 `0` 到 `2`。`expireDays` 是保留天数。

## 9. 打印机状态码

本节内容来自 SDK 包中的 `photo_printer-zh.txt`。同一份原文已放在 Demo 目录，便于客户直接转给现场人员。

| `4d000c02` | 子设备固件更新中 |
| `4d100000` | 设置选项 |
| `4d200201` | 节能模式 |

### 警告状态

| 代码 | 含义 |
| --- | --- |

警告一般可以继续完成当前作业，但应提示用户补纸、更换色带或清洁。`57000303`、`57000501`、`57000801` 建议在界面上持续显示。

| 代码 | 含义 |
| --- | --- |
| `6_inch_paper_box` | 已安装 6 寸纸盒 |
| `5_inch_paper_box` | 已安装 5 寸纸盒 |
| `3_inch_paper_box` | 已安装 3 寸纸盒 |
| `6_inch_color_box` | 已安装 6 寸色带盒 |

纸盒和色带盒尺寸必须匹配。不匹配时错误码为 `4500030A`。

### 打印缓存

`PrinterStatus.getPrinterCache()`：

| 值 | 含义 |
| --- | --- |
| 0 | 没有空间 |
| 1 | 还有 1 份数据空间 |
| 2 | 还有 2 份数据空间 |

缓存为 0 时不要继续下发打印，先等待当前份完成或调用 `ClearPrinterCache`。

## 10. 常见问题

**枚举后要等一会儿才结束。**  
局域网发现本身广播约 10 秒。已经发现的打印机会马上出现，不用等全部结束。12 秒只是 Demo 防止回调丢失的上限。

**列表里只有 IP，没有打印机名字。**  
不要只用 `Printer.NetworkPrinter` 的默认描述，它只有 `tcp:ip:port`。用发现回调里的 `info.toString()` 作为列表文字，Demo 的 `NamedNetworkPrinter` 就是这样做的。

**配网成功但打印失败。**  
BLE 只负责配网，不能拿来调用 `printerOp()`。STA 要确认打印机已经连上路由器，手机也在同一个局域网，再用查询到的 `IP:9100`。AP 要让手机改连打印机自己的 Wi-Fi，再用热点地址，常见默认是 `192.168.1.1:9100`。

**接口卡死或界面无响应。**  
搜索、连接、读状态和打印都在后台线程执行。不要在主线程调用。

**返回值是 null，但业务当成失败。**  
`null` 表示成功。只有非空字符串或抛出 `OperationException` 才是失败。
